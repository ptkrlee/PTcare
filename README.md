# PTcare · 방문운동 평가 기록지

BBS, MBI, 방문운동 서비스 만족도를 모바일·컴퓨터에서 체크하고 결과를 캡처하는 정적 웹사이트입니다. 로그인, 데이터베이스, 외부 폰트, 분석 도구는 사용하지 않습니다. 인적사항과 응답은 브라우저 메모리에만 유지되며 새로고침 시 초기화됩니다. 같은 화면에서 평가 종류를 바꾸면 인적사항은 공유하고 평가별 응답은 유지합니다.

## 실행

Node.js 20.19+ 또는 22.12+가 필요합니다. 이 환경에서는 Node.js 24.19.0을 사용했습니다.

```sh
cd /workspace/PTcare
npm ci --cache /workspace/.setup/npm-cache --no-audit --no-fund
npm run dev -- --port 5173 --strictPort
```

기본 정보(성명, 평가일, 생년월일)를 입력하고 모든 문항을 선택하면 **결과지 보기**로 이동합니다. 결과지에서 스크롤 캡처 또는 **인쇄 / PDF**로 개인 보관할 수 있습니다. 브라우저가 제공하는 PDF 저장을 사용하며 별도 서버 업로드는 없습니다. 현재 평가 초기화는 기본 정보와 다른 평가의 응답을 지우지 않습니다.

## 검증 및 배포용 빌드

```sh
npm test
npm run build
npm run test:e2e
```

실제 Chromium 브라우저 테스트는 `/usr/bin/chromium`을 사용합니다. 다른 위치의 Chromium이 있다면 `CHROMIUM_PATH=/path/to/chromium npm run test:e2e`로 지정합니다. 테스트는 채점, 0점·미응답 구분, 평가 전환, MBI 이동 방식, 초기화, 결과지, 인쇄, 모바일 너비, 새로고침 시 초기화 및 외부 요청 부재를 확인합니다. 자동 테스트에 쓰는 인물 정보는 가상의 예시입니다.

`npm run build`가 생성하는 `dist/`를 HTTPS 정적 호스팅 서비스에 배포할 수 있습니다. 빌드 명령은 `npm run build`, 게시 디렉터리는 `dist`입니다. 현재 작업에서는 외부 공개 배포나 Git push를 수행하지 않았습니다. 루트 도메인이 아닌 하위 경로에 배포할 때는 `npm run build -- --base=/경로/`를 사용합니다. 별도의 API 키나 데이터베이스가 필요하지 않습니다.

## 문항과 배점

사용자가 제공한 다음 두 HWP 문서에서 항목과 점수를 추출했습니다. 첨부 문서 자체는 저장소나 웹 배포 파일에 복사하지 않습니다.

- `서식-협회 공동 서식(활동평가지).hwp`: BBS와 MBI
- `서식-협회 공동 서식(참여동의서, 서비스 만족도 조사).hwp`: 만족도 문항과 건의사항

협약서의 개인정보 수집·서명·계약 항목은 이 사이트의 평가 목적에 포함하지 않았습니다. 문서에 적힌 수집·보관 지침을 웹사이트 저장 기능으로 구현하지 않았습니다.

- **BBS:** 14문항 × 0–4점, 총 56점. 2번의 원문 안내(2분 서기가 가능하면 3번 4점)를 화면에 표시하되 평가자가 3번을 직접 선택하게 했습니다. 원문 1번의 `여러번 사용하여`는 동작 시도 의미가 드러나도록 `여러 번 시도하여`로 표기했고, 띄어쓰기와 명백한 오탈자를 정리했습니다. 원문 자체의 경계값·표현을 보완하거나 독자적인 임상 판정 기준을 추가하지 않았습니다.
- **MBI:** 개인위생·목욕 0/1/3/4/5, 식사·용변·계단·옷입기·대소변 각 0/2/5/8/10, 보행·이동 각 0/3/8/12/15. 기본 10문항, 총 100점. 보행과 의자차를 동시에 합산하지 않습니다.
- **의자차 대체:** 원문에 의자차 0/1/3/4/5가 있으나 별표에 대한 적용 설명은 없습니다. 선택 시 보행 15점 항목을 의자차 5점 항목으로 대체하여 총 90점으로 명시하고, 100점으로 환산하지 않습니다. 기관의 대체 적용 기준을 확인해야 합니다. 일반 보행 평가가 기본입니다.
- **만족도:** 원문 10문항, 1–5점, 10–50점. 총점은 응답 점수의 단순 합산이며 원문에 없는 등급·절단점·임상 해석을 만들지 않았습니다. 건의사항은 합산하지 않습니다.

미선택 상태는 0점 응답과 구분합니다. 미완료 시 표시되는 값은 **부분 점수**이고, 최종 결과지는 기본 정보와 모든 응답을 완료해야 열립니다. 제공된 서식 기반 입력 도구이며 별도 임상 타당도 검증을 했다는 뜻은 아닙니다.

참고 사이트 `https://ktin.org/tem/`는 작업 당시 HTTP 403으로 접근할 수 없어 시각적 복제나 동일성 확인은 하지 않았습니다.

## 환경 재사용

클라우드 작업은 이미 격리되어 있으므로 `/workspace/PTcare`의 기존 체크아웃을 사용하고 별도 Git worktree를 생성하지 않습니다. 설치된 의존성과 `dist/`는 파일이며, 개발 서버 프로세스는 새 작업에서 다시 실행해야 합니다. 재실행 지침과 설치 스크립트는 환경 설정 초안에도 저장합니다.

원격 저장소가 비어 있어 이 작업은 커밋이 없는 로컬 브랜치에서 시작했습니다. 현재 소스는 작업 디렉터리의 새 파일입니다. Git 커밋·push·공개 배포는 별도로 수행해야 합니다.

## 2026-10-22 화면 개선

기본 정보 입력 후 “이 대상자 평가 시작하기”를 눌러야 평가 항목이 표시됩니다. 문항마다 “미평가 · 다음에 하기”를 선택할 수 있고, 미평가를 포함한 결과는 0점 응답과 구분한 부분 점수로 출력합니다. 화면 대비·선택 표시와 PDF 인쇄 글자색을 강화했습니다.

로그인·대상자별 자동저장 및 확장 평가 코드는 `feature/clinical-records` 브랜치에 준비되어 있습니다. 이 운영 브랜치는 아직 서버 저장이 없는 간단 기록지이며, 확장판의 실제 계정 저장을 가동하려면 해당 브랜치의 `docs/CONNECT-SUPABASE.md`에 따라 인증·데이터베이스를 연결해야 합니다.
