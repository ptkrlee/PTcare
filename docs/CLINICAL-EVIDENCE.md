## SPPB

| 영역 | 점수 계산 |
| --- | --- |
| 균형 | 양발 모아 서기 10초 1점 + 반일렬 10초 1점 + 일렬 10초 2점 / 3–9.99초 1점 / 3초 미만 0점 |
| 4m 보행 | <4.82초 4점 / 4.82–6.20초 3점 / 6.21–8.70초 2점 / >8.70초 1점 |
| 3m 보행 | <3.62초 4점 / 3.62–4.65초 3점 / 4.66–6.52초 2점 / >6.52초 1점 |
| 팔 미사용 5회 일어서기 | ≤11.19초 4점 / 11.20–13.69초 3점 / 13.70–16.69초 2점 / 16.70–60초 1점 / >60초 또는 수행 불가·팔 사용 0점 |

0.01초 단위로 입력합니다. 앞 균형 자세에서 10초 미만이면 그 영역을 종료합니다. 실패한 앞 단계와 후속 단계 시간이 동시에 있으면 모순을 알리고 점수를 확정하지 않습니다. 보행은 두 시행 중 빠른 시간, 한 시행만 유효하면 그 시간을 사용합니다. 보행 거리를 선택하지 않은 기존 4m 기록은 4m 기준을 쓰며 화면에 이를 명시합니다. 의자 검사는 팔 미사용 여부를 확인해야 양의 점수를 산출합니다.

**수행 불가 0점**과 **미실시·미평가(점수 미확정)**는 다릅니다. 총점은 3영역이 모두 결정됐을 때만 완료로 표시합니다. 여러 날짜에 걸친 검사는 표준 총점으로 해석하지 않도록 안내합니다. 연령·질환에 따라 표준 SPPB 배점 자체를 변경하지 않습니다. 기존 수기 답변은 삭제하지 않고 별도 원본으로 보여 주되 자동 총점에는 측정값만 사용합니다.

## TUG

TUG는 시간 검사이며 임의의 점수표를 만들지 않습니다. 평가일과 생년월일로 만 나이를 구합니다. 현재 CDC 적용 범위는 만 65세 이상 일반 지역사회 고령자로 제한합니다. **3m·평소 속도·신체적 도움 없음**을 확인해야 해당 기준을 비교합니다. 12초 이상은 추가 낙상 평가를 위한 선별 결과이며, 미만도 낙상 위험이 없다는 판정이 아닙니다.

다음 값은 첨부 DOC에서 확인한 **기존 연구 참고값**입니다. 최신 검증 또는 질환 전체에 적용 가능한 규준으로 주장하지 않습니다.

| 연구 | 집단·조건 | 참고값 |
| --- | --- | --- |
| Shumway-Cook et al. Physical Therapy. 2000;80(9):896–903 | 지역사회 고령자, 표준 TUG | ≥13.5초 |
| 같은 연구 | 가득 찬 물컵을 드는 과제 | ≥14.5초 |
| 같은 연구 | 20–100 중 임의 숫자에서 거꾸로 세기 | ≥15초 |
| Kristensen et al. Physical Therapy. 2007;87(1):24–30 | 고관절 골절 수술 후 6개월, 59명 | 24초 |
| Dite et al. Arch Phys Med Rehabil. 2007;88(1):109–114 | 일측 경골하 절단 후 6개월, 40명, 다회 낙상 | ≥19초 |

Shumway-Cook 값은 치료사가 “연구 참고값도 표시”를 선택할 때만 추가합니다. 인지/신체 과제는 위 과제 조건까지 선택해야 그 과제의 연구값을 표시합니다. CDC 12초를 인지/신체 과제 시간에 적용하지 않습니다. 다른 질환에는 이 값을 대입하지 않습니다. 뇌졸중·파킨슨병·알츠하이머병 등은 현재 적용 가능한 절단값을 확인하지 못했다는 안내와 실제 시간만 제공합니다.

이중과제 시간 증가율은 `(이중과제 시간 − 일반 시간) ÷ 일반 시간 × 100`의 산술값이며 별도 진단이나 위험 등급을 부여하지 않습니다. 문서의 9초 장애 발생 연구값과 MDC 값은 서로 다른 평가 목적·불충분한 원문 확인 때문에 이번 자동 위험 판정에 사용하지 않습니다.

## MoCA 및 다른 항목

- MoCA-K 유창성 11개 이상 1점, K2 춘천판은 ㄱ 단어 6개 이상 1점.
- 연속 빼기 정답 0/1/2–3/4–5개 → 0/1/2/3점. 오류 수 0–1개 → 1점, 2개 이상 → 0점.
- 원자료 수를 입력하면 해당 문항은 자동 선택·수정 잠금합니다. 수를 지우면 검사자의 선택이 가능합니다. 기존 수기 답변과 원자료를 섞어서 두 번 더하지 않습니다.
- BBS·MBI·만족도는 관찰 결과를 고르면 원래 배점으로 합산합니다. 시간만으로 안전성·도움 수준·수행 질을 추정하지 않습니다.
- 악력·30초 STS·한발 서기·신체 둘레·근육량 기록에는 검사 고유의 점수표가 없는 경우 임의의 점수를 부여하지 않습니다. 악력 최고값, BMI, 허리/엉덩이 비율, ASM/키² 등 산출 가능한 값은 자동 계산합니다. 새 질환별 진단 기준이나 연령별 정상 범위는 검증 전에 추가하지 않습니다.

자동 계산 결과는 평가 화면·결과지·관리자 읽기 전용 기록·참고 평가 기반 차팅에서 같은 규칙을 사용합니다. 수치 기준의 경계값, 미평가/0점, 다른 집단과 다른 과제로의 오적용 방지를 단위/브라우저 테스트로 검증합니다. 검사자 임상 판단을 대체하는 자동 진단으로 표현하지 않습니다.

## 현장 입력 배치와 과거 기록

TUG의 앱 용어는 신체 이중과제로 변경했으며 원문 manual dual-task에 해당합니다. 편도 거리는 3m 기본값을 치료사가 수정할 수 있습니다. 6m 보행 시간/속도는 활성 입력·계산에서 제거했고 과거 원시 값만 보존합니다. 과거 ASM 페이지의 5회 의자 일어서기 시간은 STS 항목으로 읽어 연결하며 새 STS 값이나 명시적으로 비운 값을 우선합니다.

MoCA 그림은 원문 배열/모형을 같은 문항의 큰 화면에서 제시하고 치료사가 직접 채점합니다. 화면 크기·입력 방식의 임상 동등성을 새로 검증한 것은 아닙니다. 어휘력은 단어 수로 채점하고, 지연회상은 시행 여부 확인 후 각 단어의 회상 방법에서 자동 점수를 구합니다. 단서 없이 회상 1점, 범주·선다형 단서 또는 회상 실패 0점, 미실시/미평가는 미확정입니다. 기록 영역은 어휘력 다음으로 옮겼으나 실제 시행의 표준 순서(추상력 후 회상)와 약 5분 지연 간격을 안내합니다. 이전 수기 채점은 시행 여부를 새로 선택하기 전까지 유지합니다.

길 만들기의 이전 관찰 메모에는 새 원문 배열을 뒤에 덧씌우지 않습니다. 기존 메모임을 표시하고, 사용자가 그림 지우기로 원문 과제를 시작하면 이전 스트로크를 `drawingHistory`에 보관합니다. 새 그림은 크기·방식을 함께 기록하여 결과지에서 같은 방식으로 표시합니다.

## 직접 선택, 시간 기준 확인, 완료 표시 (2026-10-23)

- 평가의 범주형 입력(두 MoCA의 회상 방법·시행 여부, 악력의 성별·주사용 손 등)은 펼쳐진 라디오 목록으로 선택합니다. 점수 선택 라디오와 원자료 입력 라디오를 구분하여 자동 점수가 입력 선택을 덮어쓰지 않습니다.
- SPPB 균형은 10초 유지, 보행은 4m <4.82초 / 3m <3.62초, 팔 미사용 5회 의자 일어서기는 ≤11.19초의 **최상위 배점 조건**을 확인할 수 있습니다. 보행·의자의 최상위 시간 기준은 일반적인 건강/질병 판정의 ‘통과’가 아닙니다. 그 외 시간대는 실제 시간을 입력하여 원래 단계별 배점을 계산합니다. 거리 변경은 보행 시간 기준 확인을 해제합니다.
- 한발 서기는 첨부 안내의 눈 뜨고 ≥30초 / 눈 감고 ≥10초 과제 목표를 확인할 수 있습니다. 임상적 정상/위험 진단으로 해석하지 않습니다.
- 확인은 별도 `*-criterion` 값으로 기록합니다. ‘통과’의 정확한 실제 시간은 선택 입력이며, 숫자를 임의로 채우거나 확인 값만으로 보행 속도를 계산하지 않습니다. 기준 미달/초과는 실제 시간 필수이며, 수치와 확인 내용이 모순되면 점수 확정/완료를 막습니다. 미평가는 0점으로 바꾸지 않습니다.
- BBS의 시간 조건이 있는 8개 문항은 최고점 선택지의 안전·도움·자세 조건을 전부 확인해야 통과입니다. 이번 버전부터 새로 선택한 다른 배점은 실제 시간(360도 회전은 좌·우 각각)을 기록해야 완료됩니다. 기존 점수 기록에는 새 입력 조건을 소급하지 않습니다. 수행하지 못했으면 0초를 기록할 수 있습니다. 시간만으로 안전/도움 수준을 자동 추정하지 않습니다. STS 30초는 검사 시행 시간이며 임의의 통과 컷오프를 만들지 않았고, TUG는 집단/시행 조건별 해석 때문에 실제 시간을 유지합니다.
- 완료 표시는 모든 채점 문항(미평가 제외), MoCA-K 교육년수, 필요한 실제 시간이 유효할 때 켜집니다. 측정형 검사는 악력(성별·주사용 손·좌우 3회), STS(반복·상지 도움·한발 좌우·5회 시간), OLS(네 조건), TUG(일반 과제와 거리·속도·도움·집단, 시작한 이중과제의 시간·프로토콜), 신체 둘레(전체 항목), 근육량(방법 및 장비 지수 또는 ASM/키) 기준입니다. TUG의 시작하지 않은 이중과제, 메모·검사자 등은 강제하지 않습니다.
- `completedAt`을 첫 완료 시 저장하고 수정 중에도 유지합니다. 미완료가 되면 해제하며 재완료 시 새 완료일을 저장합니다. 표시 날짜는 한국 시간입니다. 기존 완료 기록은 완료 시각 메타데이터가 없으므로 마지막 기록 시각을 사용합니다. 일반회원 임시 평가의 완료 정보도 메모리에서만 사용하고 서버/기기에 저장하지 않습니다.
- 인쇄는 모든 채점 결과, 회상 방법, 시행 기록, 세 그림을 A4 요약지로 배치합니다. 두 MoCA 및 나머지 10개 검사에서 일반적인 입력으로 PDF 1페이지를 확인합니다. 긴 메모·긴 자유 입력은 내용 보존을 위해 다음 페이지로 이어지며 잘라내지 않습니다. 실제 아이폰 인쇄 여백·머리말/꼬리말 설정에 따라 페이지 수는 달라질 수 있습니다.


## MoCA 원문 대조 및 기존 BBS 완료 복구 (2026-10-25)

두 판의 첨부 실시요강과 검사지 전체 문항을 다시 대조했다. 100에서 7씩 빼기의 정답 순서는 93, 86, 79, 72, 65이다. 원문에 있는 92, 85, 78, 71, 64는 첫 답이 틀려도 뒤 네 번 뺄셈이 맞으면 3점이라는 **오답 후 계산 예시**다. 화면에 정답을 먼저 표시하고 오답 예시임을 명시한다. 정답 수 입력 기반 배점은 변경하지 않았다.

판본 차이를 그대로 보존한다. 한국판은 코뿔소/뿔소, 낙타/약대를 허용하고 추상력에서 바퀴/숫자 응답을 허용한다. 춘천판은 박쥐, 기차–비행기/시계–저울을 사용하며 바퀴/숫자 응답은 오답이다. 춘천판 정육면체 12개 선, 직사각형 허용 및 시계의 로마 숫자/윤곽 밖 숫자 허용을 보완했다. 주의집중은 각 판의 원문 글자/요일 배열과 오류 정의를 표시한다.

지연회상의 범주 및 선다형 단서는 원문 그대로 판별로 제공한다. 한국판 비단의 선다형은 나일론·면·비단, 춘천판은 면·삼베·비단이다. 두 판의 학교/교회, 피리/진달래, 노랑/빨강도 구분한다. 정답과 단서는 검사자용이며 자유회상을 모두 마친 후 사용한다. 동물 그림은 원문 이미지의 해당 부분을 SVG viewBox로 표시하고, 대상자 전용 전체 화면에는 정답 이름이나 채점 항목을 노출하지 않는다.

BBS 완료 실패는 새 시간 필수 조건이 기존 점수 기록에 소급된 경우를 재현해 수정했다. 기존 14문항의 유효한 점수가 모두 있으면 완료로 표시한다. 새 응답 선택 시에만 해당 문항의 `*-time-required` 표식을 저장해 필수 시간 입력을 검증한다. 기존 응답·시간·총점·개인 기록을 일괄 수정하거나 수치를 생성하지 않는다. 실제 운영 계정의 기록은 이 작업 환경에서 직접 열람하지 못했으며, 합성 기록으로 검증했다.

그림 실행 취소는 한 포인터 스트로크(한 획) 단위다. 버튼과 캔버스에 포커스한 Ctrl+Z / Command+Z를 지원하고 변경된 획을 즉시 저장한다. 다른 그림·채점·텍스트 입력 기록은 건드리지 않는다. 결과지 캔버스는 읽기 전용이다.
