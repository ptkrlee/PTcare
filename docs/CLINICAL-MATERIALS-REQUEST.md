# 임상 기준 보완에 필요한 자료

현재 기록 기능과 확인된 첨부자료의 채점은 사용할 수 있다. 아래 추가 자동 해석은 자료를 받아 대상 집단·시행 조건·판본을 대조하기 전까지 적용하지 않는다. UI/자동저장/점수 경계값 테스트 통과를 임상 타당성 검증과 혼동하지 않는다.

1. **MMT +/− 기준표 확인 완료(2026-10-27)**: 사용자가 제공한 IMACS Form 04의 1–3쪽을 기준으로 등급별 부분 범위·중력·저항·유지/회복 시간 안내를 반영했다. 특정 기관이 다른 +/− 규칙을 쓸 경우에만 해당 기관 표가 추가로 필요하다.
2. **근긴장도**: 기본은 MAS 0·1·1+·2·3·4로 구현했다. 기관이 다른 척도(Tardieu 등)를 사용한다면 해당 원본과 실시요강이 필요하다. MAS는 수동 저항의 순서 척도로 저긴장, 구축 또는 원인을 자동 진단하지 않는다.
3. **ROM**: 현재 필요한 부위를 Full/Limited와 선택적 실제 각도로 기록한다. AROM/PROM은 각 응답 입력 당시의 검사 방식으로 함께 보존한다. 정상 각도를 자동 비교하려면 사용하는 측정 교재의 관절별 자세·고정/이동 팔 위치·기준각 표를 제공해야 한다. 첨부 HWP 기재범위는 기록 참고이며 모든 연령/질환에 공통 정상 절단점으로 삼지 않는다.
4. **추가로 필요한 AWGS 2025 원문 및 다른 대상군 규준**: 이번 첨부 AWGS 파일은 수치표가 없는 소개 사설이다. 사설이 인용한 Chen LK et al., “A focus shift from sarcopenia to muscle health in the Asian Working Group for Sarcopenia 2025 Consensus Update”, Nat Aging. 2025;5:2164–2175의 원문·수치표가 필요하다. 첨부 2022 근감소증 종설은 DXA 본문과 AWGS 2014 표1 참고값으로 반영했으며 BIA와 혼합하지 않는다. 신경근육질환/말레이시아 시설 거주 TUG 및 KFACS 5회 STS 연구는 해당 집단의 참고로 반영했다. KFACS와 PH 1분 STS는 제공된 초록만 있으므로 상세 시행·경계 포함 규칙을 확인하려면 전문/프로토콜이 필요하다. 다른 집단의 해석을 원한다면 사용하려는 논문의 제목·DOI·PDF와 적용 대상 집단, 시행 거리·속도·도움 조건, 악력계/손잡이·자세·반복 규칙, 근육량 측정 방식이 필요하다. 기존 TUG 3m·평소 속도·신체적 도움 없음·65세 이상 일반 고령자의 CDC 기준과 다른 집단 기준을 섞지 않는다.
5. **기관의 운동서비스 제공기록지 원본**: 현재 첨부된 협회 활동평가지, 수행 협약서, 90개 운동 예문을 참고해 서비스 일시·제공자·현재 상태·평가 요약·실제 운동·반응·과제·다음 계획·사진 2장을 구성했다. 특정 지자체의 실적/청구 서식과 동일하게 맞추려면 실제 제공기록지 원본이 필요하다. 법적 제출 적합성이나 의료기록 인증을 자동 보증하지 않는다.

환자 이름·연락처·얼굴이 있는 실제 사례 대신 빈 양식이나 비식별 예시를 제공해도 된다. 자료는 비밀번호나 서버 비밀키가 필요하지 않다.
