기존 90개 ID와 기록은 유지하며 활성 목록은 총 97개입니다. 새 7개는 자동 추천에서 제외합니다. 수동 추가 전 동작별 조건 확인 창을 띄웁니다. 원문 방식은 계획 카드의 ‘첨부 시나리오 방법’에서 확인·반영할 수 있습니다. 원문 방법을 읽거나 선택하는 것만으로 실제 시행·관찰·반응을 기록하지 않습니다.

기존 기본 설정(10회, 양측은 각 10회, 3세트, 유지 3초)을 유지합니다. 원문의 교대 총 10회, 수건 누르기 유지 5초, 옆누워 다리 벌리기 4세트 등 차이는 별도 표시합니다. 원문과 앱 기본값 중 어느 것도 모든 대상자에게 맞는 처방으로 간주하지 않으며 치료사가 조절합니다. 원문에 있는 수술 후 적합성·효과 표현을 보편적인 임상 판단으로 확대하지 않습니다.

## 모바일 작성

- 운동기록: 상태 / 운동 계획 / 실제 수행 / 경과기록 / 서비스 기록지·사진의 5단계. 상단 단계, 이전·다음, 전체 보기 사용. 단계 전환으로 임상 DOM을 다시 만들지 않으므로 입력·자동저장 연결을 유지합니다. 계정·대상자·회차별 마지막 화면 설정만 세션 저장소에 보존합니다.
- 사례 참고 설명은 모바일 단계 모드에서 접어서 시작합니다. 필요하면 직접 열 수 있습니다.
- 평가: 18종 평가 메뉴를 모바일 가로 메뉴로 압축하고 문항·측정값·기초 영역·관절 움직임 바로가기와 이전·다음을 제공합니다. 답변 선택만으로 다음 문항 이동이나 포커스·스크롤 변경을 하지 않습니다.
- 기존 좌우 대칭 ROM/MMT/MAS, 그림 입력, 실행 취소, 인쇄 경로는 유지합니다. 문항 이동 메뉴는 데스크톱에서 고정하지 않아 그림 영역을 덮지 않습니다.

추가 90개 후보는 [별도 검토안](exercise-candidates-90.md)이며 위 활성 목록과 별개입니다. 원문 가이드라인 접속 차단으로 개별 동작의 원문 대조는 대기 상태입니다.
