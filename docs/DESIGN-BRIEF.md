# PTcare 디자인 기준

사용자가 제공한 리핏테라피 무드보드와 요청한 추가 연핑크를 PTcare에 적용한다. 브랜드명은 PTcare를 유지한다.

- 네이비 `#17324D`: 헤더, 대상자 배너, 선택 항목의 경계, 주요 버튼.
- 민트 `#9EC9BB`: 평가/측정 공간과 선택 상태. 민트 면 위의 본문은 네이비.
- 실버 `#D9DFE8`: 정보 구분, 보조 배경, 비활성 상태.
- 골드 `#B39760`: 단계, 과제 안내, 강조선. 작은 글자는 어두운 골드 `#705524`.
- 연핑크 `#F1DCE6`: 만족도, 메모, 회상 공간, 보조 카드.

흰색은 입력창/검사 그림에 사용하고, 영역과 카드에는 명확한 색상 면을 둔다. 색만으로 상태를 전달하지 않고 라벨·선·아이콘을 병용한다. 완료는 타원형 배지, 날짜는 작은 보조 글씨로 표시한다.

그래픽은 원본 SVG로 만든 치료사와 대상자 동행 일러스트, 기록지·이동 경로, 각 평가별 선 아이콘을 사용한다. 임상 자극 그림(동물·정육면체·길 만들기)은 장식 그림으로 교체하지 않고 첨부 검사지 원본을 그대로 제시한다. 검사자 정답·힌트는 대상자용 화면에 표시하지 않는다.

모바일 회상 목록은 두 열, 고정 경계 두께와 일정한 상태 영역으로 유지하고 결과 설명이 펼쳐지며 화면 높이가 바뀌지 않게 한다. 인쇄는 잉크색/선명도를 우선하며 화면 장식과 분리한다.

ROM·MMT·근긴장도는 대상자와 마주본 배치로 표시한다. 화면 왼편에는 환자의 오른쪽(R), 오른편에는 환자의 왼쪽(L)을 배치하며 인쇄 표도 오른쪽 결과–움직임–왼쪽 결과 순서를 따른다. 저장된 left/right 키와 기존 값은 바꾸지 않는다. 목·몸통의 공통 측정은 단일 열로 유지한다. ROM은 모바일에서도 두 열로 표시하고 반복 제목·각도 라벨·세로 여백을 줄이며, 제한 각도는 선택 입력으로 유지한다.


대상자 카드는 이름 링크와 독립된 세 아이콘(평가하기·서비스 제공 계획서·운동기록지)을 제공한다. 평가 아이콘은 기초평가로 이동하며 각 분야의 화면에서도 같은 내비게이션을 제공한다. 계획서는 평가일/최종 수정 시각/계획 반영 시각을 구분하고 한국시간을 명시한다. 처리중 표시는 실제 비동기 작업과 화면 이동에 반투명 배경·회전 표시·명시적 문구로 제공하며, 항목을 연속 입력할 때는 전체 화면을 막지 않는다.

2026-10-27: 평가 순서는 기초·통증 → ROM → MMT → MAS → FAC → BBS → MBI → 노인우울 → SPPB → TUG → 한발서기 → 의자일어서기 → 악력(기존 도구 유지) → 신체둘레 → 근육량 → MoCA 두 판 → 만족도. BBS/MBI/ROM/MMT/MAS 카드는 영문약어를 주 제목으로, 한글은 보조 설명으로 사용한다. MoCA 회상은 작은 카드·안내/단서 접기·모바일3열 직접선택을 사용하며 선택상태에 따른 카드높이/스크롤위치 변경을 피한다.
